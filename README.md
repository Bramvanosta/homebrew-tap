# Bramvanosta/homebrew-tap

Homebrew casks for [Ranch](https://github.com/Bramvanosta/Ranch), a desktop client for BullMQ.

```bash
brew install --cask bramvanosta/tap/ranch        # stable releases
brew install --cask bramvanosta/tap/ranch@beta   # release candidates too
```

Ranch updates itself; `brew upgrade --cask --greedy` also picks up a new version. The casks are written by Ranch's release workflow.
